# Docker 前端验收延期记录

- 状态：延期
- 登记日期：2026-08-16
- 适用范围：Web 设置中的容器运行环境、容器 Worker Profile、容器自检和容器运行详情
- 原因：当前 Docker 相关前端仍有待处理问题，本轮按操作者要求只验收宿主机本地运行路径

已复现的前端问题：在任务创建页点击“本地”后，运行请求仍记录为
`worker_backend=container`。启用的七个本地 Profile 最终覆盖了该值，实际 Worker 均在宿主机
运行，但运行详情为每个 Worker 记录了运行环境降级提示。该问题纳入后续 Docker 前端修复范围。

本轮不构建 Worker 镜像，不启动 Worker 容器，也不把 Docker 相关代码标记为已验收。

恢复验收前需要先明确并修复前端问题，然后从 Web 页面依次验证：

1. 本地与容器运行环境切换后，所有 Profile 的运行环境显示和保存结果一致。
2. 容器自检能展示镜像、Docker 服务、CLI 和凭据各自的真实状态及错误详情。
3. 创建任务后，运行详情显示实际使用的容器运行环境，不回退到宿主机。
4. 暂停、恢复和停止能控制容器内 Worker，并在停止后确认容器已退出。
5. 容器 Worker 只加载任务目录投影的 `muteki-blackboard`，Agent 自动发现目录中没有永久副本。
