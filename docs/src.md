## 1. 工作台定位

**SRC 赏金工作台**（`/src`）面向周期更长、资料更杂、需要持续沉淀的漏洞挖掘与安全研究项目。它把主对话协作与结构化研究数据放在同一个工作台内，避免在聊天记录、零散文档和抓包工具之间来回搬运：

- **以主对话驱动研究**：在一个研究任务（`/src/tasks/<task_id>`）内描述目标、附带授权说明和已有资料，围绕同一项目持续推进分析、复测与报告整理。
- **历史研究回溯与接管**：支持通过“历史研究”入口查看既往只读任务，并在需要时显式接管继续推进。

## 2. 核心功能域

SRC 工作台围绕真实漏洞挖掘交付流程拆分为多个协同视图：

| 模块 | 作用 |
| --- | --- |
| **授权范围与策略版本** | 维护目标资产、排除资产（`excluded_targets`）和版本化的授权快照，执行与复测均校验对应授权边界 |
| **资产与来源管理** | 导入资产清单或接入外部数据源，记录观测来源并维护实体归属 |
| **流量分析与对比** | 查看与检索已采集 HTTP 交换样本，支持手工流量分析、对比及请求加签草稿 |
| **任务与待办看板** | 跟踪研究计划版本、待办事项、关联 Run 及监控任务状态 |
| **发现与证据引用** | 将漏洞发现直接绑定到原始流量与执行证据，支持逐条回溯原件 |
| **报告草稿与奖金台账** | 维护漏洞报告草稿、冻结正式报告、记录平台提交反馈、复测状态与赏金台账 |

## 3. 运行依赖与当前状态

- **JS 加签器隔离依赖**：使用 SRC JavaScript 请求加签器时，需要本机安装 `bubblewrap`（`bwrap`）以及支持 `--permission` 的 Node.js；加签器通过受限隔离进程执行，隔离设施不可用时会明确报错。
- **迭代状态说明**：SRC 工作台处于持续演进阶段，部分高级连接器、跨期项目复用与并行委派流程仍在按阶段收敛完善，各版本变更记录见 [CHANGELOG.md](../CHANGELOG.md)。
