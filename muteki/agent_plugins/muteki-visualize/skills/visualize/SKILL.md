# Muteki Visualize

将图形作为当前回答的一部分。先判断文字、表格、静态图和交互图中哪一种最有帮助；不为简单问题强行生成界面。模型选择表达方式，Muteki 负责保存、隔离渲染和把用户选择带回聊天。

## 交付

- 优先在回答中直接输出语言标记为 `muteki-visualize` 的围栏代码块，块内是完整 HTML，前后保留空行。宿主在回复完成后保存独立的消息快照并内联展示，只读模式也能使用；不需要写文件、MCP 或提高会话权限。不要用普通 `html` 代码块代替。
- 需要保留独立文件且当前 Agent 允许写入时，也可以使用以下文件交付方式。
- 使用本轮 `[Muteki 聊天展示接口]` 给出的目录；将完整 HTML 片段写入其中一个新的 `.html` 文件。没有该接口时明确说明缺少宿主展示能力，不猜测路径。
- 支持完整 HTML 文档和片段，可包含样式、SVG 和脚本；完整文档的 `<title>` 用作展开窗口和下载文件的名称。静态结构图使用 SVG 或 HTML 布局；当前聊天渲染器不会把 Mermaid 代码块自动转成图。
- 在最终回答中用空行隔开，单独输出 `muteki-visualize {"path":"本次生成文件的绝对路径.html","title":"简短标题"}`。这是跨引擎共同的展示标记，不需要调用任何平台控制工具。
- 一张图使用一个独立文件。修改图形时生成新文件并引用新路径，以保留旧消息的图形；不要覆盖历史回复引用的文件。
- HTML 源码上限为 1,000,000 UTF-8 字节。本地图片只能来自本次对话的可视化目录，使用带引号的绝对路径或 `./` 相对路径；支持 PNG、JPEG、GIF、WebP、AVIF、BMP、ICO。宿主校验图片并把内容内嵌到消息快照，后续源文件变化不会改变已发布的图。每张图片最多 5 MB，内嵌后正文最多 10 MB。超出时缩小可视范围，并保留完整数据的可读取引用；不要静默截断正文或数据。
- 宿主提供展开、源码和下载操作，不要在图内重复制作这些工具栏。导出的 HTML 保留页面和本地交互；继续聊天需要回到 Muteki。

## 表达与核验

- 结构图突出节点、边、方向和分组；交互图让选择、筛选或参数变化直接更新相关内容。只有需要模型继续分析时才回到聊天。
- 使用环境证据和用户提供的数据。区分已验证事实、假设和示意值，保留必要来源与单位，不编造比较分数。
- 图形周围只保留必要解释，不重复整张图。复杂内容可以展开细节，关键结论无需悬停也应可见。
- 适配窄屏和明暗主题。宿主实时注入当前配色与字体：使用 `--foreground`、`--background`、`--muted-foreground`、`--border`、`--font-sans`、`--font-mono` 与 `--chart-1` 至 `--chart-6`（兼容 `--viz-series-1` 至 `--viz-series-6`）等变量；不要固定白底黑字。
- 页面铺满回复列，手机约 320 px 宽时重排；外层不重复添加卡片和横幅。不要设置 `100vh` 或依赖 iframe 高度的百分比来撑高页面；宿主随实际内容调整高度，超过 2000 px 的长页面在框内滚动，也可展开查看。
- 宿主提供 `.btn`、`.btn-primary`、`.viz-row`、`.viz-controls`、`.form-label`、`.form-select`、`.form-range`、`.table` 等基础样式。表单控件使用真实标签和键盘可操作的原生元素。
- 创建后核对完整源码、引用数据和主要交互。若能使用浏览器，检查初始图形、一次状态变化和窄屏；未经渲染验证时明确说明限制。

## 本地交互与下一轮

宿主原生 API 是 `window.muteki.visualize`。需要可交互起点时读取 [assets/explorer.html](assets/explorer.html)，替换其中标注的示例选项与内容。

- `widgetState` 保存 `{modelContent, privateContent}`。`modelContent` 只放与后续问题有关的选择；`privateContent` 放折叠、缩放等视图状态。不要放凭据、大数据或整段源码。
- `setWidgetState({modelContent, privateContent})` 保存本地状态，不触发模型。总大小不得超过 16 KiB，显示保存错误；不要将保存成功描述为模型已读到选择。
- 初次读取 `widgetState`，并监听 `muteki:visualization-context` 的 `event.detail.globals.widgetState` 以恢复状态。只在用户改变状态后保存，不在加载或恢复时重写。
- 只在用户点击明确的“继续分析”按钮时调用 `requestFollowUp({prompt, title})`，在 `prompt` 中写明当前选值和分析问题，确保尚未保存过的初始选择也可理解。宿主让用户确认完整内容并放入当前输入框，用户再正常发送；不要声称已自动发送。
- `openExternal({href})` 请求用户打开外部 HTTP(S) 链接。所有本地筛选、展开、排序与计算应留在图形内。

## 运行边界

图形在独立 iframe 中运行，不能读父页面、宿主文件或凭据。不要使用 fetch、XHR、WebSocket、嵌套 iframe 或直接访问后端 API。数据随片段提供；需要新数据时发起后续聊天。可使用宿主允许的版本固定 CDN 脚本；简单图形优先零外部依赖。此插件不需要 MCP、Agent 专有 Hooks 或其他插件。
